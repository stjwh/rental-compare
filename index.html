계산 기준

상단 요약은 아래 목록에서 비교 체크한 제품만 기준으로 계산됩니다.

총 렌탈료 = 기간 프로모션 적용 후 월별 청구액 합계 + 등록/설치비 + 기타 초기비용

총 혜택 = 렌탈료 프로모션 절감액 + 기본 카드할인 + 기간 추가 카드할인 + 캐시백 + 기타 혜택

실질 총비용 = 총 렌탈료 − 총 혜택 / 실질 월평균 = 실질 총비용 ÷ 총 계약기간

관리자 로그인

제품 추가

렌탈료 기간 프로모션구간을 추가하면 총 렌탈료에 자동 반영됩니다.
예: 1~12개월 50% 할인 → 시작 1 / 적용 12 / 할인율 50% · 1~10개월 월 10,000원 → 시작 1 / 적용 10 / 월 청구액 10,000원
카드 할인 프로모션기본 카드 할인에 기간 한정 추가 할인액을 더합니다.
예: 기본 월 10,000원 할인 + 36개월간 추가 10,000원 → 시작 1 / 적용 36 / 추가 할인 10,000원
